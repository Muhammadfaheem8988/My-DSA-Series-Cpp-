A fundamental program to calculate the sum of elements within a static array. 
It highlights the importance of Array Initialization to ensure predictable behavior and avoid processing residual "garbage" data from memory.
Key Logic:
Zero Initialization: The array is declared as array[10] = {0}, ensuring every index starts at zero.
Input-Driven Summation: Iterates through n elements, adding each to a running total s.
Efficiency: Operates in linear time O(n).
