This program is a complete Student Record Management System. It utilizes an Array of Objects to store and manage student profiles, including names, dates of birth, and academic performance (GPA). 
It demonstrates the power of encapsulation by keeping data private and providing public methods for interaction.

Key Features:

* Object-Oriented Design: Each student is an instance of the Student class.

* Dynamic Search: Search functionality implemented via unique Roll Numbers.

* Data Filtering: Separate logic to filter and display students based on GPA thresholds.

* Age Calculation: Demonstrates basic arithmetic within a class method using the current year.

Technical Highlights:

* getline() Integration: Used to handle student names with spaces.

* Menu-Driven Logic: A robust do-while loop for continuous user interaction.

* Status Flags: Uses roll number checks to prevent displaying "empty" objects in the array.
