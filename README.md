##  How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Muhammadfaheem8988/My-DSA-Series-Cpp-.git
```

**2. Navigate to any folder and compile the `.cpp` file**

```bash
g++ filename.cpp -o program
```

**3. Execute**

```bash
./program
```
