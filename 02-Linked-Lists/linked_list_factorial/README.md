This program demonstrates the creation and manipulation of two separate Singly Linked Lists. 
The first list is populated with a sequence of integers, and the second list is generated by calculating the factorial of each integer from the first list.
Key Features:
Head & Tail Insertion: Showcases two different ways to add nodes: insert_as_first (O(1)) and insert_as_last (O(n)).
Data Processing: Integrates a functional approach to compute factorials while traversing the list.
Manual Memory Management: Includes a freeMemory function to traverse the list and delete nodes individually, preventing memory leaks.
Logic Flow:
Populate start list with values {3, 4, 5, 6, 7}.
Traverse start, calculate n!, and insert into startf.
Display startf and deallocate memory.
